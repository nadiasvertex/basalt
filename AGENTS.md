# AGENTS.md

## Purpose

Basalt is a C++23 widget library that follows the Cubit design system. It turns a widget tree into
paint commands and accessibility snapshots, and it never touches windows, GPUs or the operating
system's input. `README.md` describes the library for its users. This file holds the rules for
changing it.

## Read First

- `spec/CONVENTIONS.md`: mandatory C++ conventions (snake_case, `auto f() -> T`, `#pragma once`,
  `std::expected`, no raw owning pointers, warnings as errors).
- `README.md`: build options, how consumers use the library, and the HarfBuzz modes.

## Layout

| Path | Contents |
| ---- | -------- |
| `include/basalt/` | Public headers. `basalt/basalt.h` includes all of them. |
| `src/basalt/` | Implementation. Private headers such as `text/utf8.h` and `text/font_face_impl.h` live here. |
| `generated/basalt/tokens.h` | Cubit design tokens. Generated by `just tokens`; do not edit. |
| `tools/basalt_tokens/` | The token generator. |
| `tests/basalt/` | Catch2 tests. `tests/basalt/text/font_support.h` provides the bundled and system font managers. |
| `tests/data/fonts/` | Noto Sans regular and italic, used by the Latin-only text tests. |
| `tests/consumer/` | A small project that consumes Basalt by `find_package`, `add_subdirectory` or `FetchContent`. |
| `cmake/` | Compiler options, dependencies and their pins, install rules, and the include boundary check. |

## Rules

- Code lives in namespace `basalt`. Quoted includes with a directory must start with `basalt/`. The
  `include_boundaries` test enforces this and checks that `basalt/basalt.h` includes every public
  header.
- HarfBuzz is a private dependency. No public header may include it.
- Compiler flags go on `basalt_compiler_options`, which is linked privately, so they never reach
  consumers.
- New dependencies are pinned in `cmake/dependency_pins.cmake` by release archive and SHA-256.
- Text tests that need only Latin script use `basalt::test::bundled_fonts()`. Use
  `basalt::test::system_fonts()` only for font discovery and for scripts Noto Sans lacks, and skip
  when the script is missing.

## Commands

```sh
just build              # configure and build the debug preset
just test               # build and run all tests
just test sanitize      # the same, with sanitizers
just consumer           # install a release build and build tests/consumer against it
just format             # clang-format every source
just tokens <dir>       # regenerate tokens.h from the Cubit DTCG token files
```

## Tests

A test that cannot fail is worse than no test. Before trusting a new test, make it fail on purpose
by breaking the code or the expected value, confirm the failure message, and undo the change.
